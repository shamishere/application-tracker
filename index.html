Google Calendar sync Not connected
One-time setup (about 10 minutes)
  1. Open console.cloud.google.com, create a project, and enable the Google Calendar API (APIs & Services → Library).
  2. Set up the OAuth consent screen: type External, add yourself as a test user, and add the scope .../auth/calendar.events.
  3. Credentials → Create credentials → OAuth client ID → Web application. Under Authorized JavaScript origins add the address you open this page from, for example http://localhost:8000 or https://yourname.github.io (no path).
  4. Serve this file over http(s), since sign-in does not work from a file:// address. Locally: run python3 -m http.server 8000 in the file's folder and open http://localhost:8000/phd-tracker-sync.html.
  5. Paste the Client ID above and click Connect. Events are timed 9:00 to 9:30 with popup alerts, and are updated or removed when you change or clear a date.
